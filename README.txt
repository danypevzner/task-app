# Task Manager App

Простое веб-приложение для управления задачами (CRUD), демонстрирующее связку **Spring Boot Backend** и **легковесного HTML/JS Frontend**.

Проект реализует полный цикл работы с задачами: создание, чтение (с пагинацией), обновление и удаление. Отдельно выделена бизнес-логика смены статуса задачи через специализированный `PATCH` эндпоинт.

---
Требования
- Java 17 или выше
- Maven 3.8+ (или Gradle)
- База данных H2 (встроена в проект, настройка не требуется для запуска)

Сборка и запуск:
   ```bash
   mvn spring-boot:run
