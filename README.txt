# Task Manager App

Простое веб-приложение для управления задачами (Kanban-доска), демонстрирующее Spring Boot Backend.

Проект реализует полный цикл работы с задачами: создание, чтение (с пагинацией), обновление и удаление.
Добавлена глобальная обработка ошибок. Проект упакован в Docker- контейнеры.

---
Требования
- Java 17 или выше
- Maven 3.8+ (или Gradle)
- База данных Postgres

Сборка и запуск:
   docker compose up --build
